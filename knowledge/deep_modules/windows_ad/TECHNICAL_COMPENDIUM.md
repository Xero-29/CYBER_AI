## Profundización técnica específica: Windows y Active Directory

### Arquitectura Windows y modelo de seguridad
Analizar boot chain, Secure Boot, TPM, VBS/HVCI, LSASS, SAM, LSA, tokens de acceso, SID, ACL, integrity levels, object manager, servicios, RPC, WMI, WinRM y PowerShell. Distinguir token primario e impersonation token, privilegios asignados y grupos habilitados/deny-only. Revisar servicios con privilegios excesivos, rutas de servicio modificables, DLL search order, tareas programadas y permisos sobre objetos. La protección de credenciales depende de edición, versión, hardware, políticas y compatibilidad; documentar estado efectivo.

### Active Directory: bosque, dominio y replicación
Modelar forest/domain, OU, sitios, trusts, DCs, Global Catalog, DNS integrado, SYSVOL/DFSR, FSMO y replicación. Los límites administrativos no equivalen automáticamente a límites de seguridad. Revisar delegación sobre objetos, ACL heredadas, AdminSDHolder/SDProp, cuentas de servicio, SPN, gMSA, cuentas privilegiadas y grupos protegidos. Controlar cambios de esquema, trusts externos, sincronización híbrida y exposición de controladores de dominio.

### Kerberos, NTLM y protocolos
Explicar AS-REQ/AS-REP, TGT, TGS, PAC, SPN, tickets, renovación, delegación constrained/unconstrained/resource-based y canales seguros. Analizar reloj, cifrados permitidos, cuentas con preauth deshabilitada, SPN duplicados, delegación excesiva y exposición de material de autenticación. NTLM debe inventariarse y reducirse con compatibilidad medida; bloquear de forma gradual y monitorear aplicaciones legacy. LDAP signing/channel binding, LDAPS y protección de RPC deben evaluarse según topología y clientes.

### GPO, tiering y privilegios
Diseñar administración por niveles, estaciones privilegiadas, PAW, cuentas separadas, JIT/JEA y separación de roles. GPO requiere precedencia, herencia, filtrado, loopback, SYSVOL y control de cambios. Revisar ACL que permiten modificar GPO, scripts de inicio, tareas y objetos críticos. Proteger credenciales de administradores locales con LAPS y administrar secretos de servicios con gMSA cuando corresponda. La rotación debe incluir dependencias y rollback.

### Telemetría y detección
Correlacionar Windows Security Event Log, Sysmon, PowerShell logging, Defender, ETW, DNS, firewall y eventos de AD. Diseñar casos para creación de cuentas, cambios de grupos privilegiados, alteraciones de GPO, uso anómalo de tickets, cambios de ACL, ejecución remota y persistencia. La ausencia de eventos puede deberse a auditoría no configurada, retención insuficiente o bypass; medir cobertura y latencia. Normalizar eventos y preservar EventRecordID, host, canal, hora UTC y hash de exportación.

### Recuperación y continuidad de AD
Planificar backups System State, recuperación autoritativa/no autoritativa, AD Recycle Bin, recuperación de SYSVOL, rotación de secretos de dominio y validación de trusts. Definir escenario de compromiso de DC como crisis de identidad: inventariar cuentas, dispositivos, certificados, aplicaciones, sincronización cloud y dependencias. Ensayar restauración aislada y verificar integridad antes de reconectar.
